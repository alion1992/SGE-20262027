# UD2. Implantación, configuración y administración de sistemas ERP-CRM

## Instalación de Odoo 17 con Docker

En esta unidad desplegaremos **Odoo 17** junto con **PostgreSQL** mediante Docker Compose.

### Objetivos

- Comprender imagen, contenedor y volumen.
- Interpretar un `docker-compose.yml`.
- Desplegar Odoo y PostgreSQL.
- Configurar Odoo mediante `odoo.conf`.
- Preparar una carpeta para módulos propios.
- Consultar logs y administrar el entorno.

```text
Navegador → localhost:8069 → Odoo 17 → PostgreSQL
```

!!! note "RA2"
    Implanta sistemas ERP-CRM interpretando la documentación técnica e identificando las diferentes opciones y módulos.

# 13. Práctica final

## Sistema de informes empresariales

El objetivo será desarrollar un conjunto de informes profesionales utilizando la base de datos utilizada durante la unidad.

## Informes

El proyecto deberá incluir:

1. Catálogo de productos.
2. Listado de clientes.
3. Ventas agrupadas por cliente.
4. Ventas entre dos fechas mediante parámetros.
5. Informe de stock.
6. Informe con campos calculados mediante fórmulas.
7. Informe estadístico con al menos un gráfico.
8. Informe maestro-detalle mediante un subinforme.
9. Exportación de informes a PDF.

## Entrega

Se entregarán:

- Archivos `.rpt`.
- Capturas o documentos PDF con los resultados.
- Proyecto utilizado durante la unidad.

!!! success "Objetivo final"
    Crear un pequeño sistema de reporting empresarial capaz de transformar los datos almacenados en la base de datos en información útil para la organización.

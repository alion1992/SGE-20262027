# 9. Fórmulas

Las fórmulas permiten crear valores calculados dentro de nuestros informes.

## Ejemplos

Calcular un precio con IVA:

```text
PrecioConIVA = Precio * 1.21
```

Clasificar el stock:

```text
Si stock < 5 → STOCK BAJO
```

## Usos

- Operaciones matemáticas.
- Condiciones.
- Manipulación de texto.
- Tratamiento de fechas.
- Campos calculados.

## Práctica

Crear un informe de inventario que:

1. Muestre el precio sin IVA.
2. Calcule el precio con IVA.
3. Identifique productos con stock bajo.

# 11. Subinformes

Un **subinforme** es un informe incluido dentro de otro informe.

Permite representar información relacionada que sería difícil mostrar directamente en el informe principal.

## Ejemplo

```text
CLIENTE
Nombre: Empresa Ejemplo S.L.
Ciudad: Puertollano

PEDIDOS DEL CLIENTE

Pedido 1023      320,00 €
Pedido 1054      180,00 €
Pedido 1087      450,00 €
```

El informe principal puede mostrar los datos del cliente y el subinforme sus pedidos.

## Práctica

Crear una ficha de cliente que incluya un subinforme con todos los pedidos realizados.

# 📊 UD3 - Generación de informes con JasperReports

Aprenderemos **reporting empresarial** con Jaspersoft Studio y PostgreSQL.

## Objetivos
- Diseñar informes profesionales.
- Conectar con PostgreSQL mediante JDBC.
- Trabajar con SQL, campos, parámetros y variables.
- Crear agrupaciones, totales, gráficos y subinformes.
- Exportar informes.

```text
PostgreSQL → Jaspersoft Studio → JRXML → JasperReports → PDF / Excel / HTML
```

!!! info
    Comenzaremos sin programación. La integración con aplicaciones se estudiará al final.

# 📊 UD3 - Generación de informes con Crystal Reports

En esta unidad aprenderemos a diseñar y generar **informes profesionales** utilizando **SAP Crystal Reports**.

## Objetivos

- Comprender la utilidad de los sistemas de reporting.
- Diseñar informes a partir de datos empresariales.
- Utilizar agrupaciones, totales, filtros y parámetros.
- Crear fórmulas y gráficos.
- Trabajar con subinformes.
- Exportar informes.
- Integrar, al final de la unidad, informes en una aplicación .NET.

!!! info "Enfoque"
    Al principio nos centraremos exclusivamente en el **diseño de informes**. La programación con .NET se introducirá más adelante.

## Herramientas

| Herramienta | Utilidad |
|---|---|
| Visual Studio 2022 | Entorno de trabajo |
| SAP Crystal Reports for Visual Studio | Diseño de informes |
| PostgreSQL | Base de datos |
| pgAdmin | Administración de PostgreSQL |

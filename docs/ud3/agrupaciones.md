# 7. Agrupaciones y totales

Las agrupaciones permiten organizar los registros según un campo determinado.

Por ejemplo, podemos agrupar productos por categoría.

```text
PERIFÉRICOS
  Teclado             89,99 €
  Ratón               39,99 €
  TOTAL              129,98 €

MONITORES
  Monitor 27"        249,99 €
  TOTAL              249,99 €
```

## Operaciones habituales

- Contar registros.
- Sumar valores.
- Calcular promedios.
- Obtener máximos y mínimos.
- Crear subtotales.
- Crear totales generales.

## Práctica

Crear un informe de ventas agrupado por cliente que muestre un subtotal para cada cliente y un total general.
